# **主体**は、**対象**が条件を満たしたとき、**対象**を操作できる

## 背景

誰がどの場面でこの操作を行うかを書く。新しい用語は本文中に **用語**（プロジェクトでの意味）と記す。

## なぜ必要か

この操作で解決する問題、または達成したい目的を書く。

## 決めた方針

採用する動作と、適用条件や利用者が確認できる結果を書く。

### 受入テスト

- 受入テスト `実際のテストファイル::test_関数名` / `成功時の画像.png`

ブラウザー以外のテストは関数名までを指定する。

## 却下した方針

採用しない案と分かっている理由を書く。履歴も仕様上の明確な除外もなければ「却下の記録なし」と書く。
