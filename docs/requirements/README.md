# 目的

社内のAPIを一か所で探し、使う目的を伝えて申請し、承認されたら呼び出せるようにする。

# 要件

- 提供チームは、OpenAPIと接続先を選んでAPIを登録し、公開や掲載の取り下げができる。
- 利用者はAPIの用途・仕様を検索し、プロジェクトと環境を指定して利用を申請できる。
- 提供チームは申請を承認・却下し、付与した権限を取り消せる。
- 人とシステムを識別し、承認済みのプロジェクトだけが対象環境のAPIを呼び出せる。
- 掲載を取り下げると新規申請を止める。権限を取り消すと以後の呼び出しを拒否する。
- 公開、申請、判断、呼び出しの記録から、誰がいつどのAPIを利用したかをたどれる。
