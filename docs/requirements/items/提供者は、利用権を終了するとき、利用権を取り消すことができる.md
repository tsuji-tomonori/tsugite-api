# **提供者**は、**利用権**を終了するとき、**利用権**を取り消すことができる

## 背景

**利用権**（承認した対象者が、指定の商品を指定環境で呼び出す権限）には明示的な終了が必要になる。

## なぜ必要か

承認の前提が失われた後にAPIが呼び出されることを防ぐため。

## 決めた方針

取り消し後は次の呼び出しから拒否し、接続先へ転送しない。

> Quint grants.lifecycleTest — 承認、掲載停止、権限取消の区別を実際の転送回数で照合する。
> 実装検証 test_user_flow — 取消済みの権利を使用して上流が呼ばれないことを確認する。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_portal.py::test_user_flow` / `08-revoked.png`
- 受入テスト `packages/backend/tests/test_quint_grants.py::test_grant_history`

## 却下した方針

発行済みの認証情報が失効するまで呼び出しを許す方法は採用しない。
