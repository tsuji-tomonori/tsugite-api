# **利用者**は、**API操作**を試すとき、**API Docs**から呼び出しできる

## 背景

**API Docs**（商品に登録されたOpenAPIの操作を閲覧・実行する画面）には環境と認証情報の選択肢がある。

## なぜ必要か

仕様と実際の応答を同じ画面で照合するため。

## 決めた方針

許可された環境・キー・操作を選び、応答コード、本文、リクエストIDを確認できるようにする。サーバー側でも同じ利用権を検証する。利用者のログイントークンだけでの転送は拒否する。API Docsでは選択した認証情報を使ってOAuthトークン交換を行い、発行した短期トークンで呼び出す。

操作の仕様と実行欄を横に並べ、狭い画面では縦に並べる。OpenAPI原本はJSONでダウンロードできる。利用申請は専用画面で行う。入力欄には必須・任意を示し、送信中はボタンの色・文字・砂時計で状態を伝える。実行後はURLと本文を反映したcurlコマンドをコピーできる。認証トークンはシェル変数で参照する。
