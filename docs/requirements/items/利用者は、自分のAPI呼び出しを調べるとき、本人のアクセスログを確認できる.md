# **利用者**は、自分の**API**呼び出しを調べるとき、本人の**アクセスログ**を確認できる

## 背景

同じプロジェクトの複数の人が同じ商品を呼び出す。

## なぜ必要か

本人が失敗した呼び出しを特定できるようにするため。

## 決めた方針

「アクセスログ」の一覧・詳細・ダウンロードはログインした本人の呼び出しに限定する。管理者がこの画面を開いた場合も本人の範囲を適用する。
