# **利用者**は、**ポータル**を狭い画面で開いたとき、**カタログ**を閲覧できる

## 背景

商品一覧には長い識別子や応答が含まれる。

## なぜ必要か

小さな画面やキーボードでも検索条件と結果を見失わず操作するため。

## 決めた方針

390px幅でカードを1列にし、メニューを開閉できるようにする。入力ラベル・フォーカス枠・状態名を表示する。商品一覧は1ページ12件とし、検索し直したら先頭に戻す。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_portal.py::test_large_catalog` / `phone.png`

## 却下した方針

状態を色だけで区別する表示と、ページ全体の横スクロールを前提にする配置は採用しない。
