# **利用者**は、**ポータル**で一覧を開いたとき、**アクセスログ**の結果表をすぐに確認できる

## 背景

アクセスログを開くたびに期間やリクエストIDの入力欄が表示されると、目的の行を読む前に画面をスクロールする必要がある。

## なぜ必要か

利用者が最初に呼び出しの結果を確認し、必要な場合だけ対象を絞り込めるようにするため。

## 決めた方針

初期表示では検索条件を閉じる。表が画面下端を超える件数のときは、ヘッダーを含む画面全体の高さの70%以上に結果表を表示する。検索条件を開くと期間やリクエストIDを入力できる。適用後は期間と絞り込みの有無を表示する。

監査履歴でも検索条件を折りたたむ。申請、通知、問い合わせ、部署・プロジェクト、APIキーの一覧は結果を表で示す。

## 却下した方針

少ない件数を空の行で水増しして表の高さを確保する方式は、実際の件数を分かりにくくするため採用しない。
