# **利用者**は、**ポータル**を開いたとき、**ポータル**にログインできる

## 背景

管理者から招待された利用者は、社内アカウントと認証アプリを使って継手APIを開く。

## なぜ必要か

初めて利用する人も、どのサービスへのログインかを確認しながら、パスワードと認証アプリを設定できるようにする。

## 決めた方針

ポータルの日本語フォームで通常ログイン、初回パスワード変更、認証アプリの登録と確認、パスワード再設定を提供する。パスワードと確認コードはブラウザーからユーザープールの認証APIに直接送信する。

## 却下した方針

外部の汎用ログイン画面への転送は、ログイン中に表示や操作の言語が変わるため採用しない。
