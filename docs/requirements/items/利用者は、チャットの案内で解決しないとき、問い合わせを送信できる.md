# **利用者**は、**チャット**の案内で解決しないとき、**問い合わせ**を送信できる

## 背景

**問い合わせ**（利用者が運営に送る相談とその回答の記録）には個別の事情が含まれる。

## なぜ必要か

必要なときに人へ相談し、回答を同じポータルで確認するため。

## 決めた方針

利用者が明示的に送信し、管理者が一覧で回答する。依頼者は自分の問い合わせの回答を確認できる。

> Quint inquiries.inquiryTest — 受付番号の再送で重複せず、管理者の回答を送信者に表示する。
> 実装検証 test_home_chat_and_inquiry test_inquiry_requires_explicit_submission_and_private_reply — チャットから送信されるまでの導線を画面で確認する。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_portal.py::test_home_chat_and_inquiry` / `inquiry.png`
- 受入テスト `packages/backend/tests/test_chat_api.py::test_inquiry_requires_explicit_submission_and_private_reply`
- 受入テスト `packages/backend/tests/test_quint_governance.py::test_private_inquiry_history`

## 却下した方針

モデルの判断による問い合わせの自動送信は採用しない。
