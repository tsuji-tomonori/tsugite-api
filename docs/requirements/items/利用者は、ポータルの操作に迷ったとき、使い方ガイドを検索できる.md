# **利用者**は、**ポータル**の操作に迷ったとき、**使い方ガイド**を検索できる

## 背景

**ポータル**（APIの出品・検索・利用・管理を行う共通画面）では、同じ目的でも役割により操作の入口が異なる。

## なぜ必要か

操作名が分からなくても、自分の業務と役割から手順を見つけられるようにするため。

## 決めた方針

**使い方ガイド**（画面画像・手順・操作後の確認方法をまとめた役割別の案内）を画面に組み込む。利用者・提供者・管理者が語句と意味で探し、該当画面に移動できるようにする。
