# **提供者**は、**商品**の公開を申請したとき、**承認の進捗**を確認できる

## 背景

**承認の進捗**（申請時の承認順のうち、どこまで判断が済み、今は誰が担当しているか）を商品ごとに示す。初回公開と更新後の再公開では、提供者が商品を申請してから、決められた順番で承認を受ける。

## なぜ必要か

提供者が審査待ちの商品を見分け、次に誰の判断が必要か確認するため。

## 決めた方針

提供一覧に審査待ちと現在の担当を表示する。商品詳細には提出時の承認順と現在の段階番号を表示し、承認済み・承認待ち・未到達を区別する。却下と取り下げの後は、次に申請するときの承認順を示す。

> 実装検証 test_owner_sees_publication_progress — 表示のみ：商品詳細で同じ担当が複数回登場する場合の現在地と終了後の案内を確認する。

## 却下した方針

申請後に変更された承認順で進捗を表示する案は、実際の担当と一致しないため採用しない。
