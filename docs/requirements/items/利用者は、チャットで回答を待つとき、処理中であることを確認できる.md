# **利用者**は、**チャット**で回答を待つとき、**処理中**であることを確認できる

## 背景

**処理中**（質問を送信し、回答またはエラーが届くまでの状態）には、Lambdaの起動や回答の作成に時間がかかると、画面が止まったように見える。

## なぜ必要か

利用者が、質問を送り直す必要があるか迷わず回答を待てるようにする。

## 決めた方針

質問を送信すると、回答欄に「回答を準備しています…」と文字色に合わせた回転リングを表示する。端末で動きを減らす設定が有効なときは文言だけを表示する。回答またはエラーが届いたら待機表示を終了する。

> 実装検証 test_home_chat_and_inquiry test_waiting_for_a_chat_answer_prevents_a_second_submission — 表示のみ：ブラウザーで待機中の回転と動きを減らす設定、回答後の表示を確認し、単体テストで結果待ちの表示を観測する。
