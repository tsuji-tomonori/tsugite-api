# **管理者**は、**管理者**の担当者が変わったとき、**利用者**の管理者権限を変更できる

## 背景

運用担当者は個人のメールアドレスでログインし、複数人で管理業務を分担する。

## なぜ必要か

担当者の交代時に、個人の認証情報や MFA を他人に渡さずに引き継ぐため。

## 決めた方針

管理者はユーザー管理で登録済みの人に管理者権限を付与・剥奪できる。プロジェクトの所属を保ち、操作後のリクエストから権限を反映する。一般利用者の自己昇格と最後の一人の剥奪を拒否する。

> Quint administrators.handoverTest — 二人の担当者が付与・剥奪を行い、それぞれが同一セッションで管理画面を利用できるかを観測する。
> 実装検証 test_manage_admin_role — ブラウザーで対象の行を選択し、管理者権限の表示が変わることを確認する。

最初の権限変更で既存の管理者を引き継ぐ。対象者はアカウントの識別子で照合する。

> 実装検証 test_external_admin_handover — Cognito のページ送り、障害と識別子の不一致を外部名簿の応答で確認する。

### 受入テスト

- 受入テスト `packages/backend/tests/test_quint_administrators.py::test_admin_role_handover`
- 受入テスト `packages/backend/tests/test_required_member_directory.py::test_external_admin_handover`
- 受入テスト `tests/e2e/browser/test_admin_roles.py::test_manage_admin_role` / `multiple-admins.png`

## 却下した方針

一つの管理者アカウントを共有すると、権限変更の実行者を識別できない。

### 変更履歴

- 2026-11-28 管理者を個人単位で追加・交代できるようにした。
- 2026-11-28 一般メンバーへの提供・利用ロールの割り当てを廃止した。
