# **開発者**は、**変更提案**を準備するとき、分野別の**完了条件**を確認できる

## 背景

**完了条件**（変更の取り込み前に満たす検査基準）は分野ごとに異なる。

## なぜ必要か

実装者とレビュー担当者が同じ基準で判断するため。

## 決めた方針
