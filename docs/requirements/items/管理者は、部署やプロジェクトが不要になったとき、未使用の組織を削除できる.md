# **管理者**は、**部署**や**プロジェクト**が不要になったとき、未使用の**組織**を削除できる

## 背景

**組織**（所属や利用設定をまとめる部署またはプロジェクト）が改編後に残る場合がある。

## なぜ必要か

過去の記録の識別子を保ちながら、組織一覧を現状に合わせるため。

## 決めた方針

詳細から削除すると一覧から消える。子組織、所属者、接続設定、有効な利用権などが残る組織の削除は拒否する。廃止した識別子は再登録できない。

### 受入テスト

- 受入テスト `packages/backend/tests/test_unit_lifecycle.py::test_unit_retirement`
- 受入テスト `packages/frontend/tests/test_workspace_screens.py::test_unit_retirement_actions_are_admin_only`

## 却下した方針

却下の記録なし。

### 変更履歴

- 2026-11-25 #40 の移管と単純削除では成立条件が異なるため、削除を独立した要件にした。
