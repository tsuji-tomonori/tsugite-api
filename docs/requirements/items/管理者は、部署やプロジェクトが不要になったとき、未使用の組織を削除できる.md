# **管理者**は、**部署**や**プロジェクト**が不要になったとき、未使用の**組織**を削除できる

## 背景

**組織**（所属や利用設定をまとめる部署またはプロジェクト）が改編後に残る場合がある。

## なぜ必要か

過去の記録の識別子を保ちながら、組織一覧を現状に合わせるため。

## 決めた方針

詳細から削除すると一覧から消える。子組織、所属者、接続設定、有効な利用権などが残る組織の削除は拒否する。廃止した識別子は再登録できない。

> Quint directory.transferTest — 子部署が残る削除を拒否し、同種の移管先に一度だけ引き継ぐ。
> 実装検証 test_unit_retirement test_unit_retirement_actions_are_admin_only test_in_use_department_requires_transfer — 未使用条件と廃止済み識別子を実際のDB参照で確認する。

却下の記録なし。
