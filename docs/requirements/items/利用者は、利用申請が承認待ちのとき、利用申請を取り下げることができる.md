# **利用者**は、**利用申請**が**承認**待ちのとき、**利用申請**を取り下げることができる

## 背景

判断前に利用予定がなくなることがある。

## なぜ必要か

不要になった利用権の付与を防ぐため。

## 決めた方針

申請者が自分の申請を取り下げる。取り下げまたは却下の後は再申請できる。

> Quint grants.reapplyTest — 却下・取下げ後は再申請でき、重複した判断を拒否する。
> 実装検証 test_withdraw_pending test_reapply — 申請者の取下げと再申請を実際の申請APIで確認する。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_requirement_flows.py::test_withdraw_pending` / `withdrawn.png`
- 受入テスト `packages/backend/tests/test_catalog.py::test_reapply`
- 受入テスト `packages/backend/tests/test_quint_grants.py::test_grant_history`

## 却下した方針

取り下げ前の申請に対する古い判断を受け付ける方法は採用しない。
