# **管理者**は、**部署**や**プロジェクト**を管理するとき、一覧から対象の**所属**と設定を変更できる

## 背景

部署とプロジェクトの名称や所属を日々更新する。対象が増えても、変更する組織とその階層を確認できるようにする。

## なぜ必要か

一覧の上に編集フォームを表示すると、選んだ対象が画面外に出てしまい、どの組織を変更しているか確認しづらい。

## 決めた方針

部署とプロジェクトはそれぞれ独立した表で10件ずつ表示する。名称を選ぶと詳細が開き、その対象の所属・役職・リーダーを設定できる。基本設定の編集と利用状況のモニタリングには専用画面を設ける。モニタリングには呼び出し総数、エラー総数、プロジェクト別・API別の呼び出し件数を表示する。

詳細ではメールアドレス・名前・担当ロールを列でそろえ、管理者に編集・解除の操作を表示する。モニタリングの集計単位は選択した組織。所属メンバー表では役職・管理権限を確認できる。

## 却下した方針

部署とプロジェクトを同じ一覧に表示し、画面上部の共通フォームで編集する方式は、操作対象を見失いやすいため採用しない。
