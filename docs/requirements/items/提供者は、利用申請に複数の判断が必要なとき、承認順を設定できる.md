# **提供者**は、**利用申請**に複数の判断が必要なとき、**承認順**を設定できる

## 背景

**承認順**（利用権を付与するまでに判断を求める担当者とその順序）を環境に合わせて設定する。

## なぜ必要か

所属部署の確認を経てから提供者が本番利用を許可できるようにするため。

## 決めた方針

**所属部署**（申請者が所属する部署）または**上位部署**（所属部署から親子関係を上にたどった部署）のリーダーから提供者に回す順序や、特定部署を含む個別の段階を選べる。すべての段階を経て利用権を付与する。

> Quint review.orderedTest — 部署承認の前後で承認担当と呼び出しの可否が変わる。
> 実装検証 test_ordered_review test_three_environments_and_ordered_reviews — カスタム段階の順序と判断者を実際の申請履歴に照合する。
