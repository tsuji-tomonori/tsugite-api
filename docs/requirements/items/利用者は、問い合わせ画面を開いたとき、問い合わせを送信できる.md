# **利用者**は、**問い合わせ**画面を開いたとき、**問い合わせ**を送信できる

## 背景

運営へ個別に相談したい利用者は、ナビゲーションから問い合わせ画面を開く。

## なぜ必要か

チャットを経由せず、その場で相談を送り、同じ画面で回答を確認できるようにするため。

## 決めた方針

「自分の問い合わせ」に本文を入力して送信できるフォームを設ける。受付後は受付番号と最新の履歴を表示する。応答を受け取れなかった場合は本文を保持し、同じ内容を再送しても重複登録しない。
