# **利用者**は、用途に合う**商品**を探すとき、**カタログ**を検索できる

## 背景

**利用者**（業務でAPIを探し、利用を申請して呼び出す人）が使う名称と提供者が付けた商品名は異なる場合がある。

## なぜ必要か

「両替」と入力した人も、為替を扱うAPIを見つけられるようにするため。

## 決めた方針

**カタログ**（公開範囲内の商品を探す画面）では**ハイブリッド検索**（語句の一致と意味の近さで別々に順位を付け、両方の順位を統合する検索方式）を使う。環境で絞り込み、用途・提供元・仕様を確認できる。

> Quint audience.visibilityTest — 提供元・所属・属性を区別してカタログの公開判定を照合する。
> 実装検証 test_large_catalog test_catalog_displays_matching_product — 検索順位・環境による絞り込み・ページ表示を実データで確認する。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_portal.py::test_large_catalog` / `filtered.png`
- 受入テスト `packages/backend/tests/test_quint_policy.py::test_audience_policy`
- 受入テスト `packages/frontend/tests/test_required_product_views.py::test_catalog_displays_matching_product`

## 却下した方針

公開範囲外の商品を含めて件数や順位を計算する方法は採用しない。
