# **提供者**は、**商品**の利用対象を限定するとき、**公開範囲**を設定できる

## 背景

**公開範囲**（商品を閲覧・申請・呼び出しできる部署とプロジェクトの範囲）は商品ごとに異なる。

## なぜ必要か

対象外の商品名や仕様が検索結果を通じて伝わることを防ぐため。

## 決めた方針

部署を指定すると子孫部署も含む。検索・詳細表示・申請・呼び出しで同じ公開条件を確認する。

名称を公開した任意属性の値も指定できる。プロジェクト・部署・任意属性のいずれかに該当すれば閲覧対象となる。任意属性はその値への直接所属で判断する。

## 却下した方針

詳細画面だけで閲覧を制限する方法は採用しない。
