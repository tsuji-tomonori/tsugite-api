# **利用者**は、**アクセストークン**を発行するとき、**有効期間**と更新開始時刻を指定できる

## 背景

**アクセストークン**（API呼び出し時に提示する期限付きの資格）は3つの認証方式に共通する。

## なぜ必要か

更新前後に呼び出しが中断する時間を減らし、資格が使える時間を限定するため。

## 決めた方針

**有効期間**（発行後にトークンを利用できる時間）は最長60分、標準の更新開始は45分経過後とする。更新開始を有効期間内で指定でき、前のトークンは自身の期限まで有効とする。

> Quint credentials.lifetimeTest — 実行時点の最短の上限に達した瞬間から拒否する。
> 実装検証 test_credential_modes_and_validity test_credentials_console test_nested_token_lifetime — 有効時間と更新開始の実時刻を発行済みトークンで検証する。

## 却下した方針

更新開始時刻を過ぎた時点で一律に失効させる方法は採用しない。
