# **利用者**は、**ポータル**の配色を選ぶとき、**表示モード**を変更できる

## 背景

**表示モード**（ポータルの配色を端末設定・ライト・ダークから選ぶ設定）は画面上部で選択できる。

## なぜ必要か

周囲の明るさに合わせ、入力を続けながら画面を読みやすくするため。

## 決めた方針

初期表示は端末設定に従う。切替後も入力値を保持し、再読み込み後も選択を引き継ぐ。カタログの本文や操作ラベルは両モードでコントラスト比4.5対1以上とする。
