# **開発者**は、**変更提案**を検証するとき、要件ごとの結果と**証跡**を確認できる

## 背景

**証跡**（受入テストの実行記録や画面画像）を要件ごとにレビューする。

## なぜ必要か

何を検証し、どの条件が未確認かを判断するため。

## 決めた方針

Verifyのrequirement-evidence成果物で、要件原本、判定、JUnit、指定画像を確認する。未実行・スキップ・必須画像の欠落は検証未完了とする。マージ後は対応するVerifyの証跡をevidenceブランチに保存する。監査・アクセスログの生サンプルはVerify成果物で確認する。
