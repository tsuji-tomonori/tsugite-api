# **提供者**は、**利用申請**を受けたとき、**承認**または**却下**を決定できる

## 背景

**承認**（利用申請に対して指定された範囲の利用を認める判断）には理由を伴う。

## なぜ必要か

申請者が結果を理解し、必要に応じて目的や条件を見直せるようにするため。

## 決めた方針

承認または**却下**（申請理由や利用条件を踏まえて利用を認めない判断）の理由を記録し、申請者に表示する。最終承認で申請対象の利用権を付与し、古い判断の再送を拒否する。
