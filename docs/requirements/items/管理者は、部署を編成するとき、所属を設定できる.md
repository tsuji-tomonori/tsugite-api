# **管理者**は、**部署**を編成するとき、**所属**を設定できる

## 背景

**部署**（親子関係を持てる組織単位）とプロジェクトは異なる。**所属**（人と部署・プロジェクトとの関係）には役職とリーダー権限がある。

## なぜ必要か

組織の階層や兼務の実態を公開範囲と申請判断に反映するため。

## 決めた方針

部署の名称と深さを任意にし、上位部署への直接所属と複数所属を許す。所属ごとに役職・リーダーを、プロジェクトには任意の管轄部署を設定する。

> Quint membership.membershipTest — 所属付与、管理者への変更、解除後の本人の所属一覧を照合する。
> 実装検証 test_workspace_key_console test_direct_and_concurrent_memberships — 兼務・祖先部署と役割を実データで確認する。
