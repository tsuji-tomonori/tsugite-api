# **管理者**は、**プロフィール**の連絡先を補うとき、既存の**利用者**のメールアドレスを同期できる

## 背景

Cognitoで登録した人のメールが所属一覧に未登録の場合がある。

## なぜ必要か

別アカウントへの誤登録を避けて連絡先を表示するため。

## 決めた方針

運用コマンドは既定で反映候補の件数を表示する。適用時にはCognitoの利用者識別子を照合し、削除済みや識別子不一致の利用者を除外する。氏名を保ったままメールを補完する。
