# **利用者**は、**商品**を日本語で探すとき、**チャット**で候補を確認できる

## 背景

**チャット**（ホームから日本語で商品・手順の検索や問い合わせを始める画面）は、利用者の目的を検索条件に変換する。

## なぜ必要か

商品名を知らない利用者にも、関連する候補と元の情報を示すため。

## 決めた方針

元の質問と生成した検索語でハイブリッド検索し、公開範囲内の商品と役割に合う手順を返す。軽量の日本語対応OSSモデルをバックエンドとは別のLambdaで動かし、検索先・操作・出力形式を限定する。
