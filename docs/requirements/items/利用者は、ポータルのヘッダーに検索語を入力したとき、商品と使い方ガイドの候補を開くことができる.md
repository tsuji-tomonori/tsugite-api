# **利用者**は、**ポータル**のヘッダーに検索語を入力したとき、**商品**と**使い方ガイド**の候補を開くことができる

## 背景

利用者が探すものには、業務で呼び出す商品とポータルの操作手順がある。

## なぜ必要か

商品名や手順の正式な題名を覚えていなくても、今の画面から必要な情報を探せるようにする。

## 決めた方針

ヘッダーに2文字以上入力すると、閲覧可能な商品とガイド記事をそれぞれハイブリッド検索し、種類と題名を各4件まで表示する。クリックまたは上下キーとEnterで詳細を開ける。入力欄でEnterを押すとカタログで商品と関連する記事を確認できる。後から届いた古い検索結果は表示しない。

> 実装検証 test_header_search_suggestions test_superseded_suggestions — ブラウザー上の候補と遷移先、入力の変更後に応答が到着した場合を確認する。

### 受入テスト

- 受入テスト `packages/frontend/tests/test_header_search.py::test_superseded_suggestions`

## 却下した方針

入力のたびにカタログ画面へ移ると、今の作業を続けながら候補を確認できない。
