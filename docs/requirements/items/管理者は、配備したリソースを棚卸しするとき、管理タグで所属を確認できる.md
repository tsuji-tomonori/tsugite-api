# **管理者**は、**配備**したリソースを棚卸しするとき、**管理タグ**で**所属**を確認できる

## 背景

**管理タグ**（アプリケーション、管理方法、所属コンポーネントを識別するAWSリソースの情報）は費用と構成の確認に使う。

## なぜ必要か

どの機能が費用を発生させ、どの定義を変更すべきかを追跡するため。

## 決めた方針

スタックと対応リソースにApplication、ManagedBy、Componentを設定する。タグに対応しない型はテンプレートのMetadata.Tsugiteで識別する。

### 受入テスト

- 受入テスト `packages/infra/tests/test_stack.py::test_every_resource_has_ownership`
- 受入テスト `tests/e2e/aws/test_resources.py::test_deployed_resources`

## 却下した方針

タグ未対応の型を所有情報の検証から一律に除外する方法は採用しない。
