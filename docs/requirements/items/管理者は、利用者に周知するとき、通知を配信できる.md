# **管理者**は、**利用者**に周知するとき、**通知**を配信できる

## 背景

**通知**（対象者がポータルのベルで受け取るお知らせ）は運営側や提供者から届く。

## なぜ必要か

対象者が自分に関係する案内を確認済みか判別できるようにするため。

## 決めた方針

管理者は全体または所属先へ、提供者は申請元へ送信できる。受信者はベルで確認して既読にでき、未読は個人別に管理する。

> Quint notifications.readTest — 同じ通知を二度開いても他の受信者の未読数を変えない。
> 実装検証 test_independent_notification_counts — 宛先名称と所属先ごとの通知の配信を確認する。

送信先は登録したプロジェクト名と親部署で表示する。提供者にはAPI名・環境も表示する。未登録の名称は識別子で補う。

> 実装検証 test_notification_recipient_dropdown_uses_display_names — 宛先名称と所属先ごとの通知の配信を確認する。
