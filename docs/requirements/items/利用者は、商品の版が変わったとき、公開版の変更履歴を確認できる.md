# **利用者**は、**商品**の版が変わったとき、**公開版の変更履歴**を確認できる

## 背景

**公開版の変更履歴**（公開時点の仕様と変更点の記録）は、既存の連携への影響を判断する材料になる。

## なぜ必要か

追加・変更された操作やモデルを利用者が追跡できるようにするため。

## 決めた方針

API版、OpenAPI仕様版、操作・モデルの差分と提供者の説明を残す。AWSでは正規化した仕様をバージョニング有効の非公開S3に保存し、表示と実行にはDBの検証済み定義を使う。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_requirement_flows.py::test_release_history` / `versions.png`
- 受入テスト `tests/e2e/aws/test_resources.py::test_openapi_archive_versions`

## 却下した方針

最新の仕様だけを上書き保存する方法は採用しない。
