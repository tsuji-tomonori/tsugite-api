# **提供者**は、**環境**に応じて申請を受け付けるとき、**利用条件**を設定できる

## 背景

**利用条件**（申請時に確認する利用説明・規約・入力項目）は本番と検証で異なる場合がある。

## なぜ必要か

本番で必要な同意やテスト実施IDを確認してから承認に進むため。

## 決めた方針

環境ごとに説明、同意が必要な規約、必須項目と受理する値を指定する。自動承認にも同じ入力条件を適用する。

> Quint review.termsTest automatic.autoTest — 規約版・同意・追加項目の値を照合してから申請を受理する。
> 実装検証 test_publish_and_apply_from_product_page test_three_environments_and_ordered_reviews — 申請フォームの必須項目・規約版と登録値の照合を実装で確認する。
