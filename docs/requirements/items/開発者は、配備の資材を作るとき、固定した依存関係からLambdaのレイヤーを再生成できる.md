# **開発者**は、**配備**の資材を作るとき、固定した依存関係からLambdaの**レイヤー**を再生成できる

## 背景

**レイヤー**（Lambda関数と別に配布するライブラリやデータのまとまり）を複数の関数が使う。

## なぜ必要か

関数コードと依存ライブラリの配備差分を判別するため。

## 決めた方針

ロックした依存関係からレイヤーを作る。同じ入力から再生成したZIPは同じハッシュになり、関数コードだけの変更では依存レイヤーは変わらない。
