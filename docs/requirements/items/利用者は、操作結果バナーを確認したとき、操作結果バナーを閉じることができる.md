# **利用者**は、**操作結果バナー**を確認したとき、**操作結果バナー**を閉じることができる

## 背景

ポータルは、保存や更新の後に**操作結果バナー**（画面上部に成功やエラーを知らせる表示）を出す。

## なぜ必要か

結果を読んだ利用者が、入力を中断せずに次の作業へ進めるようにする。

## 決めた方針

ログイン前後の共通バナーは成功とエラーのどちらにも右端に「×」を表示する。利用者がクリックまたはキーボードで閉じると、その結果だけが消える。入力中の値は保たれ、次の操作結果は再び表示される。

> 実装検証 test_dismiss_current_notice — ログイン状態と結果種別ごとに、閉じた後と次の結果の表示を確かめる。
