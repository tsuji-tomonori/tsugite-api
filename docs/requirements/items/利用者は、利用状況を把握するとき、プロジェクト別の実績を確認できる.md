# **利用者**は、**利用状況**を把握するとき、**プロジェクト**別の実績を確認できる

## 背景

**利用状況**（ポータルのアクセス記録を集計した呼び出し件数や応答の内訳）は役割によって閲覧範囲が異なる。

## なぜ必要か

利用者・提供者・管理者が各自の責任範囲で利用の偏りや異常を見つけるため。

## 決めた方針

利用者は所属プロジェクト、提供者は提供APIと自身の利用プロジェクト、管理者と監査担当は全体を確認する。UTCの期間・間隔、API、環境、プロジェクト、応答コードで集計し、対象時間帯のログへ移動できる。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_portal.py::test_governance_console` / `metrics.png`

## 却下した方針

すべての利用者に全プロジェクトの実績を表示する方法は採用しない。
