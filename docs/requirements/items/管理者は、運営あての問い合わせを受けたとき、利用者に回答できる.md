# **管理者**は、運営あての**問い合わせ**を受けたとき、**利用者**に回答できる

## 背景

ホームや問い合わせ画面から届いた質問は受付番号単位で扱う。

## なぜ必要か

送信した本人が後から回答を読めるようにするため。

## 決めた方針

「問い合わせ」で「運営あて」を選び、未回答の行から回答を送信する。送信者は自分の問い合わせで同じ受付番号の回答を確認できる。他の一般利用者は閲覧・回答できない。

> Quint inquiries.inquiryTest — 受付番号の再送で重複せず、管理者の回答を送信者に表示する。
> 実装検証 test_inquiry_requires_explicit_submission_and_private_reply — 受付番号と回答本文・閲覧者を実際の問い合わせ履歴で照合する。
