# **リーダー**は、**利用申請**の判断を委任されたとき、**承認**または**却下**を決定できる

## 背景

**リーダー**（部署またはプロジェクトの所属に管理権限を付与された人）には担当範囲がある。

## なぜ必要か

提供者が指定した部署の事情を知る人に申請判断を任せるため。

## 決めた方針

提供者が指定した申請元部署のリーダーに判断を委任する。委任を受けた本人の申請は判断できない。

> Quint review.orderedTest — 部署承認の前後で承認担当と呼び出しの可否が変わる。
> 実装検証 test_provider_policy_console test_delegation_search_and_personal_isolation — 委任された部署と本人の所属は実際の名簿で確認する。

## 却下した方針

リーダーによる自己承認は採用しない。
