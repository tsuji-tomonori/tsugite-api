# **提供者**は、**利用条件**で申請者の属性を指定したとき、**利用申請**を**自動承認**できる

## 背景

**自動承認**（提供者の指定条件に一致した利用申請を人の判断を待たずに承認すること）は、同じ部署や役職からの申請に適用できる。条件に合う利用者から、同じ条件の申請が繰り返される。

## なぜ必要か

明示した属性に該当する申請の待ち時間を減らすため。

## 決めた方針

申請者の部署または役職と提供者の指定条件を照合する。属性条件に一致しない申請は手動で判断する。

> Quint automatic.autoTest — 属性による自動承認と、自動経路でも規約同意を必要とすることを照合する。
> 実装検証 test_provider_policy_console test_delegation_search_and_personal_isolation — 役職・部署の実データと個人・プロジェクトの申請を照合する。
