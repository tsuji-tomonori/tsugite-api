# **利用者**は、**商品**を業務で使うとき、**利用申請**を提出できる

## 背景

**利用申請**（商品を使う目的・対象者・環境を提示して承認を求める手続き）では、共同利用と個人利用を区別する。

## なぜ必要か

誰にどの環境で利用を許すかを、提供者が目的と照らして判断するため。

## 決めた方針

**プロジェクト**（APIを共同利用する単位）と**環境**（検証・準本番・本番など接続先と承認を分ける単位）を指定する。対象はプロジェクト全員または本人。所属チームがない場合は個人ワークスペースから本人として申請する。

> Quint entitlement.principalTest grants.scopeTest — 本人に限定した権利は別人・共有キー・システムから使えない。
> 実装検証 test_personal_workspace_solicits_and_uses_a_single_api — 個人ワークスペースと申請画面での入力を確認する。

商品詳細の「利用申請へ進む」から専用画面に進み、利用目的と環境別の必須項目を入力する。送信後は「自分の申請」で状態を確認する。

> 実装検証 test_user_flow — 個人ワークスペースと申請画面での入力を確認する。
