# **開発者**は、**ポータル**を初めて**配備**したとき、最初の**管理者**を招待できる

## 背景

初回配備の直後には、ポータルで利用者を招待できる管理者がいない。

## なぜ必要か

担当者が自分の認証情報で初回ログインし、利用者と組織の管理を始めるため。

## 決めた方針

開発者が GitHub Actions から手動で実行すると、CD ロールで Cognito に管理者を作成する。招待先には仮パスワードをメールで届ける。管理者が登録済みなら追加を終了する。

### 受入テスト

- 受入テスト `packages/tools/tests/test_bootstrap_admin.py::test_invite_delivers_password_by_email`
- 受入テスト `packages/tools/tests/test_bootstrap_admin.py::test_grant_only_invited_user`
- 受入テスト `packages/tools/tests/test_bootstrap_admin.py::test_existing_admin_skips_writes_in_both_jobs`

## 却下した方針

配備のたびに管理者を追加する方法と、既存の一般利用者を初回管理者に昇格させる方法は採用しない。
