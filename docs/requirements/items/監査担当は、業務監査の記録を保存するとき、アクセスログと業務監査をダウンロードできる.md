# **監査担当**は、**業務監査**の記録を保存するとき、**アクセスログ**と**業務監査**をダウンロードできる

## 背景

調査対象を期間や条件で絞ってポータルの外で確認する場合がある。

## なぜ必要か

画面で確認した範囲を、後から照合できる形式で持ち出すため。

## 決めた方針

閲覧範囲内で条件に該当するアクセスログと業務監査をJSON Lines形式で保存できるようにする。

### 受入テスト

- 受入テスト `tests/e2e/browser/test_requirement_flows.py::test_auditor_cross_checks_exports` / `access-export.png`
- 受入テスト `packages/backend/tests/test_governance.py::test_log_download_pages`

## 却下した方針

記録を全件一括でしか保存できない方法は採用しない。
