# 継手API ポータルの画面仕様

Amazon DataZoneのデータポータルで使う「提供プロジェクトのインベントリ」「公開カタログ」「プロジェクト単位のサブスクリプション」を、APIの公開と利用に対応づける。認可の単位はAPI・利用プロジェクト・環境の組み合わせとする。

|利用者の仕事|入口と操作|画面で確かめること|
|---|---|---|
|提供者が出品する|提供するAPI → APIを登録 → 下書きを保存 → 詳細で公開|下書きは提供者だけが見られる。接続確認に成功するとカタログに載る|
|利用者が選ぶ|APIカタログ → キーワード・環境で検索 → 詳細|用途・提供元・対応環境・OpenAPIの操作を、申請前に確認できる|
|利用を申請する|詳細でプロジェクト・環境・目的を指定 → 自分の申請|申請中は実行できない。申請者は取り下げられる|
|提供者が判断する|届いた申請 → 理由を記入して承認または却下|申請者が理由を読める。却下・取下げ後は再申請できる。古い判断の再送は拒否する|
|利用者が実行する|自分の申請 → APIを開く → 承認環境で実行|応答コード・本文・照合用IDを表示する。別環境、別プロジェクト、却下、権限取消では転送しない|
|掲載と権限を終了する|提供するAPIで掲載を取り下げる。届いた申請から権限を取り消す|掲載終了で新規申請を止め、既存の権限は取消まで有効とする|
|監査担当が追跡する|監査履歴 → 操作またはリクエストIDで絞る|提供元、主体、プロジェクト、環境、判断理由、実行の開始・終了・拒否を照合できる。運用ログにも同じIDを記録する|

## レイアウトと操作

- 濃紺の共通ヘッダーに製品名と利用者の所属を表示する。左ナビゲーションで探す・利用する・提供する・監査する仕事を分ける。現在地をパンくずと太字の青いメニュー項目で示す。
- 公開一覧ではAPI名、用途、提供元、環境を同じ位置にそろえる。検索条件は一覧の直前に置き、総件数と表示範囲を明示する。1ページ12件とし、検索し直したら先頭に戻る。
- 主要操作はオレンジ、リンクと補助ボタンは青、利用可能は緑、承認待ちは黄系、却下・拒否は赤とし、状態名を必ず併記する。入力にラベル、操作にフォーカス枠を付ける。
- 狭い画面ではメニューをボタンで開閉し、カードを1列に並べる。長い識別子や応答を折り返す。390px幅でページ全体の横スクロールが生じないことを確認する。
- レビューでは公開済みデータを使い、検索、ページ境界、空の検索結果、判断理由、取消後の応答を確認する。自動検証と撮影した実画面を対応づける。

参考資料：[Amazon DataZoneの公開](https://docs.aws.amazon.com/datazone/latest/userguide/publishing-data.html) ／ [サブスクリプション申請](https://docs.aws.amazon.com/datazone/latest/userguide/subscribe-to-data-assets-managed-by-datazone.html)

## AWSコンソールの表示仕様

2026年11月21日にAWSの公開画面の明暗比較とCloudscapeのVisual Refreshトークンを照合した。コンソール共通の見た目を継手APIの業務画面に適用する。

|対象|仕様|
|---|---|
|操作の強弱|AWSの更新後画面で確認した主要ボタンはオレンジ（#ff9900）と濃色文字。補助ボタンは青い輪郭にし、リンク・選択・フォーカスにも同じ系統の色を使う|
|文字と寸法|公式配布のOpen Sansを同梱し、日本語は端末の対応書体で補う。本文14px／行高20px、ページ見出し24px、カード角丸16px、入力8px、ボタン20px|
|配色の切替|初期値は端末設定。上部の「表示」でライト・ダークを選べる。設定をブラウザーに保存し、未送信の入力を保持する。OSの強制カラーでは境界とフォーカスにシステム色を使う|
|検証|ライト・ダークの実画面で本文・リンク・主要操作・入力・現在のメニューのコントラストを測る。基準は4.5:1。強制カラーでキーボードのフォーカスを確認する|

ビルドでは `@cloudscape-design/design-tokens` 3.0.119 の配布JSONから使用値を生成し、`@cloudscape-design/global-styles` 1.0.72 のフォントを同一配信元に配置する。
