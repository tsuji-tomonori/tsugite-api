# 継手API ポータルの画面仕様

Amazon DataZoneのデータポータルで使う「提供プロジェクトのインベントリ」「公開カタログ」「プロジェクト単位のサブスクリプション」を、APIの公開と利用に対応づける。認可の単位はAPI・利用プロジェクト・環境の組み合わせとする。

|利用者の仕事|入口と操作|画面で確かめること|
|---|---|---|
|提供者が出品する|提供するAPI → APIを登録 → 下書きを保存 → 詳細で公開|下書きは提供者だけが見られる。接続確認に成功するとカタログに載る|
|利用者が選ぶ|APIカタログ → キーワード・環境で検索 → 詳細|用途・提供元・対応環境・OpenAPIの操作を、申請前に確認できる|
|利用を申請する|詳細でプロジェクト・環境・目的を指定 → 自分の申請|申請中は実行できない。申請者は取り下げられる|
|提供者が判断する|届いた申請 → 理由を記入して承認または却下|申請者が理由を読める。却下・取下げ後は再申請できる。古い判断の再送は拒否する|
|利用者が実行する|自分の申請 → APIを開く → 承認環境で実行|応答コード・本文・照合用IDを表示する。別環境、別プロジェクト、却下、権限取消では転送しない|
|掲載と権限を終了する|提供するAPIで掲載を取り下げる。届いた申請から権限を取り消す|掲載終了で新規申請を止め、既存の権限は取消まで有効とする|
|監査担当が追跡する|監査履歴 → 操作またはリクエストIDで絞る|提供元、主体、プロジェクト、環境、判断理由、実行の開始・終了・拒否を照合できる。運用ログにも同じIDを記録する|

## レイアウトと操作

- 濃紺の共通ヘッダーに製品名と利用者の所属を表示する。左ナビゲーションで探す・利用する・提供する・監査する仕事を分ける。現在地を文字と選択背景で示す。
- 公開一覧ではAPI名、用途、提供元、環境を同じ位置にそろえる。検索条件は一覧の直前に置き、総件数と表示範囲を明示する。1ページ12件とし、検索し直したら先頭に戻る。
- 主要操作は青、利用可能は緑、承認待ちは黄、却下・拒否は赤とし、状態名を必ず併記する。入力にラベル、操作にフォーカス枠を付ける。
- 狭い画面ではナビゲーションとカードを縦の流れに収める。長い識別子や応答を折り返す。390px幅でページ全体の横スクロールが生じないことを確認する。
- レビューでは公開済みデータを使い、検索、ページ境界、空の検索結果、判断理由、取消後の応答を確認する。自動検証と撮影した実画面を対応づける。

参考資料：[Amazon DataZoneの公開](https://docs.aws.amazon.com/datazone/latest/userguide/publishing-data.html) ／ [サブスクリプション申請](https://docs.aws.amazon.com/datazone/latest/userguide/requesting-subscription-to-data.html)
